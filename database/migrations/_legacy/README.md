# Legacy Kigali Drive Rentals migrations (archived)

These files are **not executed** by Laravel. They are kept only as historical reference for the original hospitality platform (hotels, trips, ticketing, etc.).

Active schema for **Kigali Drive Rentals** lives in the parent `database/migrations/` folder.

If you need a clean database, use:

```bash
php artisan migrate:fresh --seed
```

See `database/migrations/README.md` for the current table list.
